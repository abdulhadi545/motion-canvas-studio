## Overview

Motion Canvas Studio is a self-contained interactive browser experience built with the HTML5 Canvas API. Users can add animated balls with different sizes and colors, observe gravity and collision behavior, control animation speed, and switch the interface language and visual theme.

The original academic file has been republished here as a clean public version without personal identifiers or student information.

## Features

- Click-to-create animated balls
- Small, medium, and large ball sizes
- Multiple color selections
- Gravity-based motion
- Boundary and ball-to-ball collision behavior
- Motion trail effects
- Animation speed control
- Ball and speed counters
- Day and night themes
- Turkish, English, and Arabic interface support
- Responsive single-page layout
- Timed interaction challenge

## Implementation

The project is intentionally dependency-free:

- **HTML5 Canvas API** for drawing
- **JavaScript classes** for ball state and behavior
- **requestAnimationFrame** for smooth rendering
- **CSS animations and responsive styling**
- **Translation objects** for multilingual labels
- **Pointer interaction** for adding objects to the canvas

## Run Locally

Download the repository and open index.html in a modern browser. No build tools, packages, or credentials are required.
